# Safari・ホーム画面版の招待参加

## 修正内容

Safari、アプリ内ブラウザ、ホーム画面に追加したWebアプリは、ブラウザの保存領域を共有しない場合があります。以前は参加先のグループIDをlocalStorageだけに保存していたため、同じGoogleアカウントでも、別の保存領域では「招待リンクから参加してください」と表示されていました。

- 参加済みグループを `userGroups/{Google UID}` に記録し、ログイン時・フォーカス復帰時に、実際のグループ所属を確認して復元します。
- Safari等に残っている従来の参加情報は、所属確認後に自分のアカウントへ同期します。既存ユーザーは更新後のSafari版を一度開くと同期できます。
- 招待コードをログイン・画面切り替えの間保持し、参加成功時に消去します。
- 「友達の投稿」に、アプリを移動せず招待リンクを貼り付けて参加できる欄を追加しました。カレンダーからも「友達の招待・参加を開く」で同じ共通画面へ移動します。これにより、外部アプリのブラウザで参加してからホーム画面版に戻る必要がありません。
- 初回作成用の「友達のグループを作る」は補助的な場所に移し、招待された方が誤って別のグループを作りにくくしました。
- iPhoneの通知設定に同じ「ホーム画面に追加」の説明が二重に出る問題も修正しています。

## 利用者への案内

1. ホーム画面に追加したアプリを開きます。
2. 招待を受けたときと同じGoogleアカウントでログインします。
3. 復元されない場合、「友達の投稿 → 招待リンクを貼り付けて参加」に友達から届いたURLをそのまま貼り付けます。
4. 「このリンクで参加する」を押します。以後、このホーム画面版でグループを利用できます。

招待された人は、新しいグループを作らないでください。招待の期限が切れている場合は、参加中の友達に新しいリンクを作ってもらってください。アプリの削除・再インストールやブラウザデータ削除は不要です。

## 自動復元用ルールの公開（管理者が一度実行）

Cloud Shellの既存の `basho-fcm-deploy` ディレクトリ内で実行します。

```sh
git pull --ff-only
npx --yes firebase-tools@15.36.0 deploy --project basho-friends --only database
```

追加する `userGroups` は本人だけが読み書きでき、実際に所属しているグループだけを登録できます。他人のグループの一覧を取得したり、所属していないグループへ参加したりする権限は追加しません。FCM Functionsの再公開は不要です。

既存のFirebaseコンソール側ルールにリポジトリへ未反映の変更がある場合は、公開前に差分を確認してください。

ルール公開前でも、既存の参加処理・このアプリ内への招待リンク貼り付けは利用できます。その場合、端末をまたぐ自動復元だけが利用できないため、別の保存領域で一度リンクを貼り付けて参加します。

## 検証

- `node --test tests/friends-invites.test.mjs tests/friends-restore.test.mjs`: 招待保持、期限・別サイト・不正リンク、アカウント切替、旧参加情報の移行、ネットワーク失敗時の保持。
- `CHROMIUM_PATH=/usr/bin/chromium python3 tests/friends-pwa.browser.py`: 独立したブラウザ保存領域での参加先復元、別アカウントへの分離、URLがログイン中に消える場合、ルール公開前の貼り付け参加と再読み込み。
- Database Emulator: userGroupsの本人限定アクセス、未参加グループ・他人の設定・余分なフィールドの拒否。

iPhoneの実機では、Safari版で参加後、ホーム画面版で同じアカウントにログインして復元されることを確認してください。自動復元は参加先の記録を復元する機能であり、Googleログイン状態や端末内だけの写真をブラウザ間でコピーする機能ではありません。

## 友達の画面・招待の画面・グループを抜ける（v83）

- 招待・参加・参加者一覧・ログアウトは「みんなの記録」の上にある友達の列から開く「友達」画面にまとめた（`flow-screens.js` の `basho-friends-screen`）。
- 招待リンクには、トークンのほかに招待した人の名前（`from`）・参加人数（`n`）・期限（`exp`）が入る。ログイン前の招待画面（`basho-invited`）に表示するためのラベルで、参加できるグループを決めるのはトークンだけ。名前は20文字までに切り、制御文字と `<>` を除いて表示する。
- 「このグループを抜ける」は、自分の `groups/$group/members/$uid` と `userGroups/$uid` を消す。送った写真・ひとこと・スタンプはグループに残り、抜けた本人は読めなくなる。もう一度参加するには有効な招待が要る。
- 参加者が自分だけのグループは抜けられない（写真を開ける人も消せる人もいなくなるため）。別のグループへは招待リンクから参加できる。
- ルール `groups/$group/members/$uid` は、招待による新規作成に加えて「本人による削除」だけを許可する。他人の削除・内容の書き換えは拒否（`tests/firebase-friends-rules.test.mjs`）。
